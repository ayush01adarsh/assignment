# assignment
### Task 1: Basic Mathematical Operations

This program takes two numbers as input from the user and performs the four basic mathematical operations (addition, subtraction, multiplication, and division), displaying the results.

**Features:**
*   Takes user input for two numbers.
*   Performs addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
*   Outputs the result of each operation.

### Task 2: Personalized Greeting

This program takes the user's first and last name, combines them, and prints a personalized greeting message.

**Features:**
*   Takes user input for first and last names.
*   Concatenates strings to form a full name.
*   Prints a personalized greeting.
